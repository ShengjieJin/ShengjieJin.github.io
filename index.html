ReSAIL: Mitigating Collapse in Iterative Agent Self-Distillation

Shengjie Jin, Hengbo Xu, Zelong Sun, YuJie Guo, Zhiwu Lu

arXiv 2026Paper ↗Code ↗

TL;DR ReSAIL mitigates performance collapse in iterative LLM agent self-distillation by selecting informative interaction steps and preserving behavior conditioned on privileged information as the student becomes the next teacher.

View figure ＋

AnchorGUI: Asymmetric Memory for Dual-Scale Learning in GUI Navigation

Shengjie Jin, Zelong Sun, Hengbo Xu, Yanbiao Ma, Zhiwu Lu

ECCV 2026Paper ↗

TL;DR AnchorGUI compares expected and observed GUI transitions to build asymmetric memory, retaining screenshots for mismatches while compressing consistent steps into text. This supports immediate error correction within a trial and efficient experience distillation across trials.

View figure ＋

VisionPulse: Dynamic Visual Sparsity for Efficient Multimodal Reasoning

Hengbo Xu, Shengjie Jin, Yanbiao Ma, Zhiwu Lu

ICML 2026Paper ↗

TL;DR VisionPulse adapts both the number and selection of visual tokens at each decoding step using visual attention, without additional training. This reduces redundant visual computation and shortens reasoning traces while maintaining comparable accuracy on the evaluated benchmarks.

View figure ＋

Retrieval-Augmented Meta Test-Time Training for Multimodal Reasoning

Shengjie Jin, Zelong Sun, Hengbo Xu, Yuyao Zhang, Dong Jing, Zhiwu Lu

Manuscript · 2025Paper ↗

TL;DR RAM-TTT retrieves relevant examples and reranks them using model confidence, then adapts a vision-language model at test time through leave-one-out episodes that predict each retrieved example’s answer using the others as context.

View figure ＋

MMRole: A Comprehensive Framework for Developing and Evaluating Multimodal Role-Playing Agents

Yanqi Dai, Huanran Hu, Lei Wang, Shengjie Jin, Xu Chen, Zhiwu Lu

ICLR 2025Paper ↗Code ↗

TL;DR MMRole provides a dataset of character profiles and image-based dialogues, a specialized role-playing agent, and evaluation with reference answers. Together, these support developing and assessing agents that interpret images while staying consistent with a character’s personality, knowledge, and speaking style.
